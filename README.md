# Sorting Algorithm Visualizer

## Project Overview
Sorting Algorithm Visualizer is an interactive desktop application developed using Python and Tkinter. It helps users understand sorting algorithms through graphical visualization.

## Features
- Generates random numbers for sorting
- Displays numbers as graphical bars
- Visualizes sorting operations step by step
- Provides a simple graphical user interface
- Helps students understand sorting concepts

## Technologies Used
- Python
- Tkinter
- Random Module

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python sorting_visualizer.py
```

## Learning Outcomes
- Understanding sorting algorithms
- Python GUI development using Tkinter
- Working with arrays and loops
- Visualizing algorithm execution
